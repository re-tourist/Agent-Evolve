# Execution plans

Use `.agent/plans/NNN-short-name.md` for multi-module work, major stages or architecture
changes. Small fixes need no plan. Read current goals and architecture first.

A plan must state objective/current Milestone/scope, audited initial state and user
changes, source/version anchors, assumptions/unknowns/risks, small work units with
observable exit gates, exact validation commands, progress and actual outcomes.
Update it as evidence changes. Record major decisions in `docs/DECISIONS.md`.
Do not declare completion from compilation alone, hide failing checks or substitute
Mock output for real evaluation. Paid work requires the approved budget separately.
