## 实现了什么，尚未证明什么

`semantic.py` + 既有 `experiment.py` worker 提供：

- 仅可观察 Trace、固定 Policy、工具定义与官方标量 Reward 的 allowlist 输入；

- 9类语义分析接口：工具选择、参数、结果理解、意图不匹配、Policy、沟通确认、
  规划终止、Simulator/Environment归因、Unknown。类别由Qwen语义分析提出，非关键词分类。
- 原有确定性工具/终止观察作为证据入口；显式位置、原文引用校验、事实/假设、
  责任方、影响与一般化建议。非法引用被拒绝；实例标识不能进入改进建议。
- 对引用有效的判断进行同一Qwen的第二次质询，保留原文、复核与实际发送输入。
  **这不是独立真值判定，同模型复核仍会重复误判。** 无引用的自由建议不进入Reflection。
- 可配置预算/划分/64Steps；20任务真实基线池；两组相同的失败/成功混采，minibatch3、
